For AI agents reading this page

You are setting up the RAPP Brainstem (RAPP = Rapid Agent Prototype Platform) for the user and connecting it to Claude Code as an MCP server named brainstem. Follow these steps in order. Ask the user before approving any sign-in for them, and never type their credentials. The user needs a GitHub account with GitHub Copilot.

1. Check whether the Brainstem is already running

curl -sf http://localhost:7071/health

If this returns JSON with "status":"ok", skip to step 3. Don't reinstall over a running Brainstem, because the installer restarts it.

2. Install it

macOS / Linux:

curl -fsSL https://kody-w.github.io/rapp-installer/install.sh | bash

Windows (PowerShell):

irm https://kody-w.github.io/rapp-installer/install.ps1 | iex

Run it in the background. When it finishes installing it keeps running as the server. Watch its output. If it prints a GitHub device code, show the user the code and https://github.com/login/device, then wait while they approve it. Poll curl -sf http://localhost:7071/health every few seconds until it answers. A first install can take a few minutes. If sign-in was skipped, the user can finish it at http://localhost:7071/login.

3. Connect Claude Code

This installs a small bridge next to the Brainstem and registers it. macOS / Linux:

mkdir -p ~/.brainstem/claude
curl -fsSL https://kody-w.github.io/rapp-brainstem-claude/brainstem_mcp.py -o ~/.brainstem/claude/brainstem_mcp.py
~/.brainstem/venv/bin/python -m venv ~/.brainstem/claude/venv
~/.brainstem/claude/venv/bin/pip install -q "mcp>=2,<3" requests
claude mcp add --scope user brainstem -- ~/.brainstem/claude/venv/bin/python ~/.brainstem/claude/brainstem_mcp.py

Windows (PowerShell):

$d = "$env:USERPROFILE\.brainstem\claude"; mkdir $d -Force | Out-Null
irm https://kody-w.github.io/rapp-brainstem-claude/brainstem_mcp.py -OutFile "$d\brainstem_mcp.py"
& "$env:USERPROFILE\.brainstem\venv\Scripts\python.exe" -m venv "$d\venv"
& "$d\venv\Scripts\pip.exe" install -q "mcp>=2,<3" requests
claude mcp add --scope user brainstem -- "$d\venv\Scripts\python.exe" "$d\brainstem_mcp.py"

If claude mcp get brainstem already shows a server, ask the user before replacing it.

4. Confirm

claude mcp get brainstem

It should say Connected. The tools load in new sessions, so tell the user to restart Claude Code or run /mcp. Then call the capabilities tool and tell the user which agents their Brainstem has. The bridge gives two tools. chat(user_input, session_id?) sends a plain-language request; pass the returned session_id to continue the conversation. capabilities() reports status, model and agents.
